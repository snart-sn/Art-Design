================================================

Files:
- index.html
- style.css

- assets/poster-training.jpg

HOW TO USE
1. Keep the folder structure unchanged.
2. Open index.html in Chrome, Edge or Firefox.
3. To publish online, upload the whole folder to your hosting/cPanel or deploy it to GitHub Pages/Netlify/Vercel.
4. Edit text, phone numbers and WhatsApp link inside index.html as needed.

The website is responsive and includes:
- Mobile navigation
- Portfolio category filters
- Portfolio image lightbox
- Scroll reveal animations
- WhatsApp call-to-action
- Responsive service cards
- Modern Snart navy/gold visual theme

DRIVE PROJECTS
==============
Six additional portfolio projects have been added using Google Drive previews.
The website uses:
- Google Drive thumbnail URLs for project cards.
- Google Drive /preview URLs inside the project lightbox.

IMPORTANT:
The Google Drive files must be shared so that visitors can view them (for example,
"Anyone with the link" with Viewer permission). If a file is private, its preview
will not be visible to normal website visitors.
